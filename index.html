📱 How to Import into Anki

  1. Desktop (Mac / Windows / Linux): Download the `.apkg` file and double-click it. Anki will automatically open, import all 189 cards, and sync the media images.
  2. iPhone / iPad (AnkiMobile): Download the `.apkg` file in Safari, tap "Share", and select "Copy to AnkiMobile".
  3. Android (AnkiDroid): Download the file, open AnkiDroid, tap the 3 dots menu ➔ Import, and choose the downloaded file.
